# Expense Tracker

This is an expense tracker application that uses Vue 3 for the frontend and Laravel for the backend API. The app allows users to manage their expenses, categorize them, and visualize spending patterns. It features group management, expense management, and charts to track spending over time.

## Technologies Used

- **Frontend**: Vue 3, Vite, Tailwind CSS
- **Backend**: Laravel (PHP)
- **Authentication**: Laravel Sanctum
- **State Management**: Pinia (for Vue)
- **Charting**: Chart.js
- **API**: REST API built with Laravel

## Features

- **User Authentication**: Users can register, log in, and manage their accounts using Laravel Sanctum.
- **Expense Management**: Users can create, update, delete, and view expenses.
- **Group Management**: Expenses can be grouped, and users can track spending by group.
- **Charts**: Visualize spending data with pie charts.
- **CSV & PDF Export**: Export expenses as CSV or PDF files.
- **Responsive Design**: Built with a mobile-first approach using Tailwind CSS.
